# FIR_AXI4LIGHT_verilog_progect
В данном репозитории расположены все необходимые исходные файлы для создания программируемого КИХ фильтра с числом коэффициентов до 127. Загрузка коэффициентов и их колличества происходит через AXI4LIGHT транзакции. Загрузка входных отсчётов и выгрузка обработанных происходит через AXIStream интерфейс.
Проект создан под плату xczu2cg-sbva484-1-e и расчитан на тактовую частоту 500 МГц.
